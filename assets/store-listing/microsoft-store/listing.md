## Description (up to 10,000 characters)

Deskveet shows where your disk space went and cleans what is safe to clean.

Most full drives are full of things nobody chose to keep: build folders, package caches, browser caches, crash
dumps, Windows error reports, temporary files and the downloads tools leave behind. Deskveet knows where these
live, measures them, and tells you what each one is before anything is touched.

Every rule explains itself. Built-in rules cover Temp, crash dumps, Windows error reports, the shader cache,
Chrome, Edge, Brave, Firefox, VS Code, Discord, Teams, Gradle, npm, NuGet, Visual Studio and more. Each one says
what happens if you delete its items and how they come back.

You see it first. Nothing is cleaned until you have seen the list and confirmed it. Items go to the Recycle Bin,
so you can restore them, and an undo log keeps track of what moved where.

It also scans any folder into a treemap, finds large and duplicate files, removes apps with their own
uninstallers, finds what removed apps left in AppData, lists what starts when you sign in, and lives in the system
tray with quick actions.

Deskveet installs for your account only and never needs an administrator. It has no accounts and no tracking; its
only connection is a daily check on GitHub for updates, which you can turn off.

## Product features (up to 20, 200 characters each)

- See where your space went with a fast folder scan and a scrollable treemap
- Built-in rules for Temp, crash dumps, browser caches, app caches and developer tools
- Every rule says what you lose and how it comes back
- Preview everything before it is cleaned; items go to the Recycle Bin
- Undo log with Restore for every clean
- Find large old files and duplicate files by content
- Uninstall apps with their own uninstallers and find leftovers in AppData
- See what starts when you sign in
- System tray: clean safe caches, quit apps, keep awake, eject drives, lock, sleep, restart, shut down
- Add your own rules with a live preview
- Size history per rule, low-disk alerts and scheduled cleaning
- No administrator needed, no accounts, no tracking
